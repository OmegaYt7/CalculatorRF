# Калькулятор по линейной и векторной алгебре

Веб-калькулятор: матрицы, СЛАУ (матричный метод, Крамер, Гаусс), векторы.
Показывает промежуточные действия, считает точно (дроби), сообщает об ошибках.

## Запуск
Откройте `index.html` двойным кликом. Сервер и установка не нужны.

## Тесты
```
node tests/run-tests.js
```

## Бесплатный хостинг (GitHub Pages)
1. Создайте репозиторий на GitHub и загрузите все файлы проекта.
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт будет по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Структура и пояснения к коду: см. [STRUCTURE.md](STRUCTURE.md).
