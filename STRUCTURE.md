## Как это работает: путь одного нажатия

1. Кнопка (`app.js`, `buildButtons`) вызывает `execute`.
2. `execute` читает нужные клетки: `MatrixGrid.read()` → `Fraction.parse` для каждой клетки.
3. Вызывается математика, например `LA.matrix.multiply(A, B)`; она возвращает `Log`.
4. `render.js` рисует `Log` на странице.
5. Любая ошибка ловится в `execute`:
   - `MathError` → «Невозможно выполнить операцию: …» (оранжевое);
   - `InputError` → «Ошибка ввода — Матрица A, строка 1, столбец 2: …» (красное);
   - всё остальное → «Сбой в ходе выполнения операции: …».

## Вопросы, которые вам вероятно зададут

- **Почему дроби, а не float?** `0.1+0.2` в float ≠ `0.3`. С `Fraction` (BigInt) ответ всегда точный → надёжность выше 98%. См. `fraction.js`.
- **Зачем `gcd`?** Сокращает дробь: `2/4 → 1/2`, чтобы `eq` сравнивал просто числитель и знаменатель.
- **Как работает `eliminate`?** Идёт по столбцам: ищет ненулевой элемент, ставит его на строку `r` (при перестановке считает `swaps`), вычитает строку `r` из нижних с коэффициентом `f = M[i][c]/M[r][c]` → под опорным элементом нули. Число опорных столбцов = ранг.
- **Почему det = (−1)^swaps · произведение диагонали?** Свойства определителей (лекция 3, сл. 10–11): прибавление строки, умноженной на число, det не меняет; перестановка двух строк меняет знак; у треугольной матрицы det = произведение диагонали.
- **Как проверяется совместность СЛАУ?** Теорема Кронекера–Капелли: система совместна ⇔ r(A) = r(A|b). После прямого хода ищется строка `0 … 0 | β`, β ≠ 0 → тогда r(A|b) = r(A)+1, решений нет.
- **Что если r(A) < n?** Столбцы без опорного элемента — свободные переменные; остальные выражаются через них (общее решение).
- **Зачем `verify`?** Самопроверка: решение подставляется обратно в `A·x = b`. Если не сошлось — «сбой».
- **Векторное произведение:** разложение определителя `| i j k ; a ; b |` по первой строке. **Смешанное:** `([a,b], c)`, плюс самопроверка определителем из координат.
- **Почему `<script>` вместо `import`?** Страница открывается двойным кликом (`file://`), а ES-модули там блокируются браузером. Все файлы кладут функции в общий объект `window.LA`.
- **Время ≤ 10 с:** размер матрицы ограничен 8×8; на практике вычисление занимает миллисекунды (время показывается под ответом).
